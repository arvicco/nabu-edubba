# Sinograph Addenda

The school's reference shelf. Every character the courses teach
gets one page here: where its shape comes from (per the
scholarship, with honest uncertainty labels), a memory hook we
invented and say so, and a real cited line from the classical
corpus where the character does its work. Frequencies are counted
over the classical books themselves — the same base that orders
the courses.

- [Signs — one page for every character]({{ '/sinographs/addenda/signs/' | relative_url }})
- [Pinyin — how to read the voice]({{ '/sinographs/addenda/pinyin/' | relative_url }})

The shelf covers both
[Sinographs 101]({{ '/sinographs/101/' | relative_url }}) and
[Sinographs 102]({{ '/sinographs/102/' | relative_url }}): every
taught character has its page.
