# Study decks — real spaced repetition

The warm-ups in every chapter and the
[drill shelf]({{ '/hieroglyphs/addenda/drills/' | relative_url }})
space your practice in *curriculum* time. For spacing in real,
calendar time — the single best-evidenced tool for long-term
retention — use a scheduler. You do not need one built into this
site: <a href="https://apps.ankiweb.net/">Anki</a> is free, runs
everywhere, and ships the modern FSRS scheduler. We provide the
cards; it provides the clock.

## The decks

One card per sign taught in the course: the glyph on the front;
keyword, name, readings, meaning, the sign's memory hook, and one
real corpus line with its URN on the back (the aes corpus is
license class attribution throughout, so every card carries its
line).

- <a href="{{ '/assets/decks/edubba-hieroglyphs-101.txt' | relative_url }}" download>edubba-hieroglyphs-101</a> — 53 cards
- <a href="{{ '/assets/decks/edubba-hieroglyphs-102.txt' | relative_url }}" download>edubba-hieroglyphs-102</a> — 21 cards

## Three steps

1. Install <a href="https://apps.ankiweb.net/">Anki</a> (desktop
   first; the mobile apps sync to it).
2. **File → Import**, choose the downloaded file. The file
   declares its own settings (tab-separated, HTML on); accept
   the Basic note type, front and back.
3. In the deck's options, enable **FSRS** — Anki's built-in
   modern scheduler — and let it decide when you next see each
   card. Answer honestly; the algorithm does the rest.

Add cards only as you reach their chapters, or import everything
and suspend what you have not met — both work; the second lets
the deck run ahead of you as a preview.
