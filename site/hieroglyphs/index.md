# The Hieroglyphs School

Egyptian writing is the second great logophonetic tradition Edubba will
teach, and like cuneiform it is not one script but a sequence: hieroglyphs
proper, the cursive hieratic hand, demotic, and Egyptian's own Coptic
afterlife. This school will be built the same way as the others — a
foundations course on how the writing system works, then a literacy track
that takes a reader toward genuine reading of real Egyptian texts, with
further courses for the tradition's later phases. As with every Edubba
school, the goal is not facts about the script but the ability to read it.

## Course catalog (planned)

- **101 · Foundations** — planned. How Egyptian hieroglyphic writing works
  as a system. Prerequisite for everything below.
- **102 · Middle Egyptian literacy** — planned. A literacy track building
  toward reading real Middle Egyptian texts.
- **2xx · The wider Egyptian world** — planned. Further courses across the
  tradition's later phases:
  - Hieratic — planned.
  - Demotic — planned.

  - Ptolemaic — planned.
