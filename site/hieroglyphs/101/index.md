# Hieroglyphs 101 · Foundations

**The first course of the Egyptian school.** No prerequisites. By
the end you will know how Egyptian hieroglyphic writing works as a
system, read and write a first inventory of signs, and — the promise
that matters — **read real royal names and a real Egyptian formula**
carved four thousand years ago, in the original.

This course is about the writing system itself, not yet about the
Egyptian language: the Middle Egyptian literacy track builds on it.
If you have taken
[Cuneiform 101]({{ '/cuneiform/101/' | relative_url }}), you will
recognize the machinery — word-signs, sound-signs, silent
classifiers — meeting it a second time in a second great tradition
is the fastest way to see that it is not a curiosity but a *design*.
